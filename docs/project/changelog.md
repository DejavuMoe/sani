# 更新日志

<p class="lead">每个版本的变化都记录在这里。版本号遵循[语义化版本](./versioning)；在 1.0 之前，次版本号的变化也可能包含不兼容的修改，届时会在这里写明升级方法。</p>

## v0.9.0

2026-10-09 · 实施已批准的 R3：标签颜色与编辑、创建默认值、专用网页信息代理及大文件分片上传，统一后台交互。首次启动迁移至 schema 5，升级前请阅读下方说明。

- 标签新增 12 个柔和预设、系统取色器及 HEX/RGB/HSL 输入，保存为六位 HEX；支持就地修改名称与颜色，所有引用同步更新，旧命名色继续兼容。
- 设置页新增自动短码长度、排除易混淆字符、单文件大小上限，以及关闭/直连/代理抓取网页信息。设置持久化；显式环境变量优先，并按字段锁定后台。分享自动 ID 仍至少 10 位。
- 未显式配置时，单文件上限改为 99,000,000 字节；后台可设 1–4096 MB。超过 25,000,000 字节自动以独立请求串行分片，失败可在当前页面重试已确认偏移之后的数据，取消/过期/重启会回收临时片；完整校验成功前不创建分享。每个凭据最多 2 个、实例最多 8 个进行中上传，总预留空间最多 8 GiB。
- 新增可选 `SANI_META_PROXY`，支持 HTTP、HTTPS、SOCKS5 及可选认证。专用模式将已验证的公网 IP 固定给代理，保留目标 Host/TLS SNI；失败不直连，忽略 NO_PROXY，凭据不返回后台。关闭抓取后刷新保留已有信息。
- 导入仅保留 Sani 原生 CSV/JSON 和 Shlink 明确格式；提供两种可下载的 Sani 范例。移除其他产品专属字段和任意包装的模糊匹配，未识别格式在写入前拒绝。原始 Shlink CSV 在隔离数据库验证，重复导入不增加链接或访问量。
- 减轻输入整框光晕和上传区域 hover；统一键盘、复制、打开、回车图标与操作按钮；隐藏创建面板不再获取焦点，修复窄屏设置页域名撑宽。
- 更新中英文 API、配置、导入、部署与安全说明，增加代理协议/DNS、schema 升级、设置优先级、分片失败重试及浏览器回归测试。

### 不兼容变更与升级

- **数据库 schema 5：** 扩展标签颜色约束，保留标签 ID、链接关联与统计。升级前正常停止服务，并备份数据库、`files/` 和配置。v0.8.x 及更早版本不能直接打开 schema 5；回退需恢复升级前同次完整备份，不能只换旧镜像。参阅[备份与恢复](../guide/operations#backup)。
- **导入白名单：** 不再兼容 Sink、YOURLS、Kutt 等专属导出或任意 JSON 包装；原生 JSON 必须包含 `app: "sani"`、`version: 1`、`links`。其他来源先对照[标准示例](../guide/import-export)转换。已有链接和导入时的短码冲突处理不变。
- **文件上限单位：** 未设置时使用十进制 99 MB，后台输入也使用十进制 MB；显式 `SANI_MAX_FILE_MB` 继续按旧版 MiB 计算，优先于后台设置。分片不绕过完整文件上限，刷新页面或重启后不续传。按需检查反代请求体上限、超时和 `/api/` 缓存规则。

## v0.8.0

2026-10-08 · 修复 Shlink 原始 CSV 导入与受限访问缓存，明确 CDN 配置及分享文件回收。数据库 schema 仍为 4，无新增迁移。

### 修复

- 支持直接导入 Shlink Web Client 导出的 `short_urls.csv`，识别其用 `|` 分隔的标签，保留短码、目标、标题、创建时间和累计访问数；不改变 Sani CSV 的 JSON 标签格式与校验限制。补充真实导入、重复导入及后台文件上传回归测试。
- 带有效期或访问上限的跳转统一发送 `Cache-Control: no-store`，避免 301/308 缓存绕过后续限制；未设限制的永久跳转仍允许缓存一天。文件与文本下载的无效 Range 等错误响应也保持 `no-store`。
- 默认部署改用 `./sani-data` 绑定目录，禁止 Docker 自动创建目录。首页、双语 README、快速开始、部署页和生成器均在启动命令前给出 `65532:65532` 权限初始化步骤，并补全已有目录的修复方法。使用旧命名卷的实例须先备份、迁移数据，再切换挂载。
- 时区选择改用与站点一致的自定义搜索菜单，替换浏览器原生下拉框；支持键盘选择、移动端触摸及明暗主题。

### 文档

- 双语文档给出主域名与文件域名默认绕过 CDN、仅缓存管理端静态资源的 Cloudflare 规则，并说明浏览器缓存的永久跳转无法被源站撤回。
- 明确过期、访问耗尽和停用不会删除内容；手动删除后的软删除、异步回收、短码复用、备份保留以及 SQLite WAL/SHM 的含义。修正“阅后即焚”和严格一小时恢复期限的表述。

### 不兼容的修改

带有效期或访问上限的跳转改为禁止缓存，依赖缓存的客户端将重新回源校验；HTTP 状态码和目标不变。默认 Compose 从命名卷改为需预先初始化的绑定目录，不能直接用新示例替换已有挂载而不迁移数据。

- 升级前备份数据库、文件与配置，将镜像更新为 `ghcr.io/dejavumoe/sani:v0.8.0`。已有实例保留当前数据挂载，例如 `./data:/data`，无需为跟随新示例切换目录。检查 CDN 规则并清除此前缓存的动态响应；浏览器已缓存的永久跳转可能仍持续到原缓存到期。Shlink 导入前检查导出文件未携带的有效期、停用和访问上限设置，导入后核对 `created` / `skipped`。

- 普通修改与批量启用/停用按每条链接的提交顺序严格递增更新时间，避免较早开始但较晚提交的请求、同毫秒修改被管理端误判为旧响应；元数据刷新继续保留更新时间。

- JSON 响应使用标准 HTML 字符转义，解码后的字段值与 JSON 导入导出内容保持不变。
- 保护上传请求持有的临时文件和正式文件，直到保存数据库记录或失败清理完成，避免文件清理任务误删仍在上传的内容。
- 在写事务内依据最新记录决定是否重新抓取标题，更新网址或刷新元数据不再覆盖并发保存的手工标题。
- 管理端忽略迟到的列表与正文响应，保留已保存或删除的数据状态；旧分页响应会重新请求，删除后刷新计数。退出失败时保留认证界面并显示可重试错误。
- CI 增加真实进程的认证、分享、CLI 密码重置及停机备份恢复 smoke；管理端 axe 检查覆盖中文/英文与浅色/深色主题。
- 对齐双语产品范围、缓存与统计边界、代理信任和停机备份升级说明；文档站增加逐页摘要、canonical、语言关联、分享 metadata 与 JSON-LD，并在构建后校验实际 HTML、sitemap、robots 和 404 收录规则。
- 修复改密与登录并发时旧密码校验结果仍可签发会话的问题；后台改密、环境变量同步和 CLI 重置原子更新密码并撤销会话，撤销失败时回滚密码。
- 修复缓存失效后的请求可能复用旧加载结果的问题，避免停用或更换短码后仍通过旧加载访问链接与分享。
- 限制 HTML 图标候选为 32 个，限制 base 和 HTTP(S) 图标地址为 8192 字节，避免相对地址展开放大内存占用。
- 书签小工具和手机分享仅预填网址与标题，核对并手动点击“缩短”后才创建或复用链接。
- CSV 导出为可能被电子表格解释为公式的字段添加保护前缀；需要无损迁移时使用 JSON。修复极大导入点击数导致统计溢出的问题，超出 int64 范围时按上限显示，保留正常范围内的整数精度。
- 文档页接入 Ecoku 评论，支持中英文及深浅色主题；每页独立讨论，切换主题保留评论草稿。

### 不兼容的修改

从 v0.5.0 升级时，数据库 schema 仍为 4，没有新增迁移。本次按[版本与兼容](./versioning)以次版本发布，包含以下行为调整。升级前正常停止服务，备份数据库、`files/` 与配置，并检查密码配置及导入导出流程；完整步骤见 [备份与恢复](../guide/operations#backup)。

- **CSV 公式保护**：可能触发电子表格公式的字段增加单引号前缀，重新导入会保留该前缀，可能改变原始标题等字段。无损迁移网址链接与标签请重新从原实例导出 Sani JSON；不要批量删除 CSV 中的单引号，因为它也可能是原始内容。完整实例恢复仍需数据库、文件与配置的配套备份。
- **书签与手机分享**：外部传入的网址和标题只预填，必须核对后手动确认创建。依赖自动建链的流程请改用已认证的 API，或保留人工确认步骤。
- **密码长度**：设置和更换密码统一要求至少 8 个 Unicode 码点、最多 1,024 个 UTF-8 字节；API、`SANI_PASSWORD` 与 `sani passwd` 使用同一限制，多字节字符也计入字节上限。升级前检查环境变量，超长配置会阻止启动；若已有超长密码，请通过 `sani passwd` 重置为合规密码，重置会撤销会话。拒绝的密码不会改变已有密码和会话。
- **过期时间**：创建与修改要求 RFC 3339 时间晚于现在，转换到 UTC 后年份在 0000–9999 内，并按毫秒保存。导入中过期时间非空但格式非法、早于 Unix 纪元或超出 UTC 范围时，该行以 `expires_invalid` 跳过，不再静默变成永久有效；Unix 秒转毫秒也检查溢出。请检查 `skipped` 并修正后重试；确需永久有效时使用空值或导入值 `0`。

## v0.5.0

### 新增

- 创建和编辑短链接、文本、文件分享时可选多个标签并新建带颜色的标签；支持按标签与“未标记”筛选，标签数量与搜索、类型筛选分别计算。桌面与移动端沿用现有布局；创建时间保留在详情中。

- 每条链接最多 5 个标签，名称最多 24 个 Unicode 码点；支持 5 种颜色，不区分大小写去重。标签仅供管理员管理，访客页面不显示。

### 数据库升级

- 首次启动自动将数据库升级至 schema 4，增加 `tags` 和 `link_tags` 表及筛选索引，旧链接初始无标签。迁移保留原有数据、链接 ID 与统计。

### 修复

- 防止较晚返回的统计或元数据响应覆盖刚保存的标签与其他链接修改。
- 修复移动端标签弹层在滚动条预留区域被裁切，以及图表的隐藏辅助表格导致页面出现额外空白的问题。
- 修复部署配置生成器误改文件下载域名的问题：nginx 与 Caddy 配置保留完整输入，构建时核对生成的域名、环境变量和证书路径。
- 明确主域名同时提供短链接与 `/p/` 分享页，文件下载域名仅用于下载和原始文本；同步中英文生成器提示、部署指南和配置说明。

## v0.4.0

2026-10-06 · 修正访问计数、持久化与停机边界，完善备份指引和文档体验。使用文件访问上限的用户请先阅读“不兼容的修改”。

### 不兼容的修改

- 文件和原始文本中，符合[计数规则](../guide/statistics#counted)的每个成功 `200`/`206` GET 请求都计一次访问，包括续传、非零起点和后缀 Range；`304`、`412`、`416` 及打开文件失败不扣次数。依赖多段下载的客户端请调高上限或关闭访问上限；网络中断后重试也会消耗新次数。
- 数据库迁移到 schema 3，链接 ID 不再重用。首次启动前备份数据库与文件；回退到旧程序必须恢复升级前的备份，不能直接打开 schema 3。

### 修复

- 删除并重新创建链接时，旧链接未写入的点击不再串到新链接。
- 刷盘提交期间，API 总数不再重复计数；并发请求和被替换的缓存条目共享访问额度。
- 反复写入失败后，合并的来源列表仍有数量上限，并保留累计点击。
- 停机等待进行中的请求和后台任务，最终刷盘有独立期限，失败以非零退出码报告；部署示例留出 30 秒停止时间。
- 演示数据脚本不再打印密码；设计比对脚本按字面匹配短码，避免将输入解释为正则表达式。

### 验证与文档

- 增加计数、HTTP 条件请求、迁移、失败重试、停机和完整备份恢复回归测试。
- 增加 1千/1万/10万链接容量工具，记录延迟分位数、内存、SQLite 等待、刷盘与 WAL；普通列表计数去掉不必要的内容表关联。
- 修正文档中的在线文件备份和最多丢失两秒的承诺，区分实时总数与已提交聚合；统一版本显示并检查关键文档语义。
- 更新文档站及设计工具的构建依赖，CI 增加 JavaScript 依赖审计。
- 统一文档正文中链接、强调和行内代码两侧的空格，长行内代码在小屏换行，滚动条跟随深浅主题；简化首页，并更新文档站上线状态。
- 修复 `source-map-js` 构建依赖漏洞，更新 SQLite 和构建工具，增加 Go、JavaScript/TypeScript、Python 与 GitHub Actions 的 CodeQL 检查。
- CI、代码扫描与发布使用 Ubuntu 24.04；固定 mise 版本，消除旧工具链缓存与重复恢复 Go 缓存导致的警告。

### 升级

1. 从 v0.3.1 或更早版本升级前，停止所有 Sani 实例并确认正常退出，备份整个数据目录及当前配置。有文件分享时，数据库与 `files/` 必须来自同一次停机期间，见[配套备份](../guide/operations#backup-files)。
2. 检查文件和原始文本的访问上限。续传、多段请求和中断后的重试可能消耗多次额度；按用途调高上限或设为不限。
3. 更新程序或镜像并启动，数据库会自动迁移到 schema 3。配置项和 HTTP API 数据结构不变；确认健康检查、登录、已有短链、文件下载和统计正常。
4. 如需回退，先停止新版本，再在空目录或新数据卷中恢复升级前的完整备份，然后使用旧版本。不要让旧程序直接打开迁移后的数据库，也不要混用不同时间的数据库与文件目录。

## v0.3.0

2026-10-01 · 文本和文件：在同一个控制台里分享一段文字、一段代码或一个文件。用 API 令牌写脚本的，请先看“不兼容的修改”。

### 新功能

- **文本和文件**：链接输入框上方新增“文本”和“文件”两个标签页，可以分享纯文本、带行号的等宽代码，或者不超过 64 MB 的文件。在页面任意位置粘贴一段文字或一个文件也能直接开始。访问者在 `/p/{短码}` 页面上阅读、复制或下载；有效期、访问上限、停用和统计都和链接一样。见[日常使用](../guide/usage#shares)。
- **文件域名**：原始文本和文件下载由 [`SANI_FILES_URL`](../reference/configuration#sani-files-url) 设置的第二个域名提供。它指向同一个 Sani，只提供分享的内容，也没有任何登录会话。分享文件必须设置它，分享文本不需要。大小上限由 [`SANI_MAX_FILE_MB`](../reference/configuration#sani-max-file-mb) 设置。反向代理的配置见[部署](../guide/deploy#files-domain)。
- 从文件域名下载时，`curl` 和 `wget` 也计入访问，因为人们本来就常用它们下载文件；续传、爬虫和链接预览不计入。见[统计](../guide/statistics#shares)。
- 列表可以只看链接、文本或文件；搜索也会匹配文件名和文本的第一行。
- 新接口 `POST /api/texts`、`POST /api/files` 和 `GET /api/links/{id}/text`；链接对象新增 `kind` 和 `content` 字段，`GET /api/links` 支持按 `kind` 筛选。见 [HTTP API](../reference/api#shares)。
- 分享的文件放在数据目录下的 `files/` 里，`sani backup` 会提醒你一并复制。

### 不兼容的修改

- `GET /api/links` 和批量接口现在也包含文本和文件，它们的 `url` 为空。只处理短链接的脚本，请加上 `?kind=url`。
- `p` 成为保留短码，因为 `/p/` 下放的是分享。已经存在的 `/p` 链接照常跳转，但不能再新建这个短码。
- JSON 请求体超过大小上限时，现在返回 `413 too_large`，而不是 `400 bad_json`。

### 升级

启动时会自动升级数据库结构。要分享文件，需要为文件域名添加 DNS 记录，在反向代理里加上这个域名并调大请求体上限，再设置 `SANI_FILES_URL`，每一步见[部署](../guide/deploy#files-domain)。从此以后，备份时除了 `sani.db`，还要备份 `files/`。

## v0.2.0

2026-10-01 · 批量操作，以及为 1.0 做的准备。用 API 令牌写脚本的，请先看“不兼容的修改”。

### 新功能

- **批量操作**：在列表里勾选多条链接，一次启用、停用或删除，删除可以撤销。点列表上方的“选择”，或者按 <kbd>X</kbd> 开始；<kbd>Shift</kbd> 加点击可以勾选一段范围。见[日常使用](../guide/usage#bulk)。
- 新接口 `POST /api/links/bulk`，一次修改最多 500 条链接，见 [HTTP API](../reference/api#bulk)。

### 不兼容的修改

- `GET /api/tokens` 改为返回 `{"items": [...]}`，和链接列表的格式一致，以后可以在不破坏脚本的前提下增加字段。直接把响应当作数组读取的脚本，改为读取其中的 `items`。

### 文档

- 新增[版本与兼容](./versioning)一页，说明哪些东西受版本号约束，以及 1.0 前后的区别。

## v0.1.0

2026-09-30 · 第一个公开发布的版本。

### 跳转与统计

- 跳转目标缓存在内存中，分为 64 个分片；不存在的短码单独缓存，数量有上限；同一个短码的并发未命中只查询一次数据库。
- 点击在内存中聚合，每 2 秒在一个事务里写入 SQLite；服务停止时写入剩余的点击。
- 统计总点击、每日点击、来源网站和最近一次访问。`HEAD` 请求、预取、爬虫、链接预览、命令行工具和管理界面里的点击不计入。
- 每条链接可以设置有效期、访问上限、跳转方式（301、302、307、308），也可以停用。
- 短码支持任何语言的字母和数字，不区分大小写；自动生成的短码不使用容易混淆的字符。
- 访问者的查询参数默认拼接到目标网址上。
- 404 和 410 页面按访问者的语言显示中文或英文。

### 管理界面

- 在页面任意位置粘贴或拖入链接即可缩短，结果自动复制。
- 自动获取网页标题和网站图标。
- 链接列表支持搜索、三种排序和近 14 天的点击走势；详情页有每日点击、来源排行和二维码（PNG、SVG）。
- 全部操作可以用键盘完成；删除可以撤销。
- 书签小工具，以及 Android 分享菜单（添加到主屏幕后）。
- 中文和英文，浅色和深色主题，适配手机。

### API 与数据

- JSON API 覆盖管理界面的全部功能，支持 API 令牌。
- 导出为 JSON 或 CSV；从 Sani、Shlink、Sink 和 CSV 文件导入，已有的短码不会被覆盖。

### 部署与运维

- 一个静态链接的二进制文件，内嵌管理界面；Docker 镜像基于 `scratch`，约 24 MB。
- 全部配置通过 `SANI_*` 环境变量完成，启动时检查。
- 首次设置密码需要启动日志里的设置码，也可以用 `SANI_PASSWORD` 指定。
- `sani backup` 在线备份数据库，可以输出到标准输出；`sani passwd` 重设密码；`sani healthcheck` 用于容器健康检查。
- 提供 Docker Compose、systemd、Caddy 和 nginx 的示例配置。
- 镜像发布在 GHCR，支持 `linux/amd64`、`linux/arm64` 和 `linux/arm/v7`；二进制文件覆盖 Linux、macOS、Windows 和 FreeBSD，附 `SHA256SUMS` 和构建来源证明。

### 安全

- 密码使用 argon2id；会话和令牌只保存哈希；登录和首次设置按客户端限流。
- 拒绝跨站请求；管理界面使用严格的内容安全策略。
- 抓取标题和图标时只访问公网地址，在解析域名后和建立连接时各检查一次。

### 文档

- 中英双语的文档站，包括部署配置生成器、交互演示和性能图表。
- 构建时把配置项、API、错误码、命令行、保留短码和压测数据与源码逐项核对。
