# 更新日志

<p class="lead">每个版本的变化都记录在这里。版本号遵循[语义化版本](./versioning)；在 1.0 之前，次版本号的变化也可能包含不兼容的修改，届时会在这里写明升级方法。</p>

## Unreleased

文本和文件：在同一个控制台里分享一段文字、一段代码或一个文件。用 API 令牌写脚本的，请先看“不兼容的修改”。

### 新功能

- **文本和文件**：链接输入框上方新增“文本”和“文件”两个标签页，可以分享纯文本、带行号的等宽代码，或者不超过 64 MB 的文件。在页面任意位置粘贴一段文字或一个文件也能直接开始。访问者在 `/p/{短码}` 页面上阅读、复制或下载；有效期、访问上限、停用和统计都和链接一样。见[日常使用](../guide/usage#shares)。
- **文件域名**：原始文本和文件下载由 [`SANI_FILES_URL`](../reference/configuration#sani-files-url) 设置的第二个域名提供。它指向同一个 Sani，只提供分享的内容，也没有任何登录会话。分享文件必须设置它，分享文本不需要。大小上限由 [`SANI_MAX_FILE_MB`](../reference/configuration#sani-max-file-mb) 设置。反向代理的配置见[部署](../guide/deploy#files-domain)。
- 从文件域名下载时，`curl` 和 `wget` 也计入访问，因为人们本来就常用它们下载文件；续传、爬虫和链接预览不计入。见[统计](../guide/statistics#shares)。
- 列表可以只看链接、文本或文件；搜索也会匹配文件名和文本的第一行。
- 新接口 `POST /api/texts`、`POST /api/files` 和 `GET /api/links/{id}/text`；链接对象新增 `kind` 和 `content` 字段，`GET /api/links` 支持按 `kind` 筛选。见 [HTTP API](../reference/api#shares)。
- 分享的文件放在数据目录下的 `files/` 里，`sani backup` 会提醒你一并复制。

### 不兼容的修改

- `GET /api/links` 和批量接口现在也包含文本和文件，它们的 `url` 为空。只处理短链接的脚本，请加上 `?kind=url`。
- `p` 成为保留短码，因为 `/p/` 下放的是分享。已经存在的 `/p` 链接照常跳转，但不能再新建这个短码。
- JSON 请求体超过大小上限时，现在返回 `413 too_large`，而不是 `400 bad_json`。

### 升级

启动时会自动升级数据库结构。要分享文件，需要为文件域名添加 DNS 记录，在反向代理里加上这个域名并调大请求体上限，再设置 `SANI_FILES_URL`，每一步见[部署](../guide/deploy#files-domain)。从此以后，备份时除了 `sani.db`，还要备份 `files/`。

## v0.2.0

2026-10-01 · 批量操作，以及为 1.0 做的准备。用 API 令牌写脚本的，请先看“不兼容的修改”。

### 新功能

- **批量操作**：在列表里勾选多条链接，一次启用、停用或删除，删除可以撤销。点列表上方的“选择”，或者按 <kbd>X</kbd> 开始；<kbd>Shift</kbd> 加点击可以勾选一段范围。见[日常使用](../guide/usage#bulk)。
- 新接口 `POST /api/links/bulk`，一次修改最多 500 条链接，见 [HTTP API](../reference/api#bulk)。

### 不兼容的修改

- `GET /api/tokens` 改为返回 `{"items": [...]}`，和链接列表的格式一致，以后可以在不破坏脚本的前提下增加字段。直接把响应当作数组读取的脚本，改为读取其中的 `items`。

### 文档

- 新增[版本与兼容](./versioning)一页，说明哪些东西受版本号约束，以及 1.0 前后的区别。

## v0.1.0

2026-09-30 · 第一个公开发布的版本。

### 跳转与统计

- 跳转目标缓存在内存中，分为 64 个分片；不存在的短码单独缓存，数量有上限；同一个短码的并发未命中只查询一次数据库。
- 点击在内存中聚合，每 2 秒在一个事务里写入 SQLite；服务停止时写入剩余的点击。
- 统计总点击、每日点击、来源网站和最近一次访问。`HEAD` 请求、预取、爬虫、链接预览、命令行工具和管理界面里的点击不计入。
- 每条链接可以设置有效期、访问上限、跳转方式（301、302、307、308），也可以停用。
- 短码支持任何语言的字母和数字，不区分大小写；自动生成的短码不使用容易混淆的字符。
- 访问者的查询参数默认拼接到目标网址上。
- 404 和 410 页面按访问者的语言显示中文或英文。

### 管理界面

- 在页面任意位置粘贴或拖入链接即可缩短，结果自动复制。
- 自动获取网页标题和网站图标。
- 链接列表支持搜索、三种排序和近 14 天的点击走势；详情页有每日点击、来源排行和二维码（PNG、SVG）。
- 全部操作可以用键盘完成；删除可以撤销。
- 书签小工具，以及 Android 分享菜单（添加到主屏幕后）。
- 中文和英文，浅色和深色主题，适配手机。

### API 与数据

- JSON API 覆盖管理界面的全部功能，支持 API 令牌。
- 导出为 JSON 或 CSV；从 Sani、Shlink、Sink 和 CSV 文件导入，已有的短码不会被覆盖。

### 部署与运维

- 一个静态链接的二进制文件，内嵌管理界面；Docker 镜像基于 `scratch`，约 24 MB。
- 全部配置通过 `SANI_*` 环境变量完成，启动时检查。
- 首次设置密码需要启动日志里的设置码，也可以用 `SANI_PASSWORD` 指定。
- `sani backup` 在线备份数据库，可以输出到标准输出；`sani passwd` 重设密码；`sani healthcheck` 用于容器健康检查。
- 提供 Docker Compose、systemd、Caddy 和 nginx 的示例配置。
- 镜像发布在 GHCR，支持 `linux/amd64`、`linux/arm64` 和 `linux/arm/v7`；二进制文件覆盖 Linux、macOS、Windows 和 FreeBSD，附 `SHA256SUMS` 和构建来源证明。

### 安全

- 密码使用 argon2id；会话和令牌只保存哈希；登录和首次设置按客户端限流。
- 拒绝跨站请求；管理界面使用严格的内容安全策略。
- 抓取标题和图标时只访问公网地址，在解析域名后和建立连接时各检查一次。

### 文档

- 中英双语的文档站，包括部署配置生成器、交互演示和性能图表。
- 构建时把配置项、API、错误码、命令行、保留短码和压测数据与源码逐项核对。
