## 核心特性

- **粘贴即得**：在管理界面任意位置粘贴链接并回车，即刻生成短链接并复制到剪贴板。后台自动抓取网页标题和图标，便于辨识。
- **极速跳转**：跳转目标常驻内存，统计写入完全脱离关键路径。单台笔记本每秒可处理约 13 万次跳转，且每次点击精准计数（详见[性能](../internals/performance)）。
- **统计实用**：记录总点击、每日趋势、来源站点与最近访问时间；自动过滤爬虫、预览请求、浏览器预取和管理员自身点击。
- **掌控由你**：支持设置有效期、访问上限、临时或永久跳转，支持随时停用。修改目标网址即刻生效。
- **兼顾文本与文件分享**：支持在 `/p/…` 下分享笔记、代码或文件，同样支持设置有效期、访问上限与统计（详见[日常使用](./usage#shares)）。
- **极简部署**：单二进制内嵌管理界面，搭配单一 SQLite 文件。Docker 镜像约 25 MB，无需 Redis、PostgreSQL 等外部服务。
- **中文友好**：原生支持 `s.example.com/简历` 等中文短码；管理端与公开页面均内置中英双语。

## 适用场景

Sani 适合需要**完全自主掌控**短链接的个人用户：用于博客、周刊、社媒分享，提供稳定持久的短链接，免去第三方服务商关停、改则或插广告的担忧；也适合在私有服务器或小规格 VPS 上随手部署。

若你需要以下功能，Sani 可能并不适合：

- **多用户协作**：仅设单管理员密码，无多账号、团队或权限体系。
- **深度访客分析**：不收集地理位置、设备、浏览器等隐私数据（如需分析请在目标站点部署工具）。
- **复杂流量分流**：不支持按地域、设备或权重分流。

## 设计取舍

**单人掌控。** 仅设单一登录密码，脚本与自动化使用 API 令牌。省去多用户系统，大幅减少维护负担与攻击面。

**统计从简。** 仅存储聚合数据（各链接每日点击数与来源域名），不记录逐条访问流水。数据库体积稳定不膨胀，无访客隐私泄漏风险（详见[统计口径](./statistics)）。

**跳转优先。** 一切设计以低延迟、高可靠的跳转为核心。落库、统计聚合与元数据抓取均异步进行，不阻塞跳转。

**零外部依赖。** 单进程即全部服务。备份仅需复制单个数据库文件（若有文件分享则加上文件目录），迁移只需移动对应文件。
