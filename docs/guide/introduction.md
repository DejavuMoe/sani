# 介绍

<p class="lead">Sani 是面向个人的自托管短链接、文本与文件分享服务。它运行在你自己的服务器上，由单个管理员管理，支持标签、过期与访问限制，以及聚合点击统计。</p>

## 核心特性

- **粘贴即得**：在管理界面任意位置粘贴链接并回车，即刻生成短链接并复制到剪贴板。后台自动抓取网页标题和图标，便于辨识。
- **缓存跳转**：命中缓存时不查询数据库，点击在内存中聚合后批量写入。公开压测记录了约每秒 13 万次跳转与计数核对结果；这是特定环境的测量，非容量或持久性保证（详见[性能](../internals/performance)）。
- **统计实用**：记录总点击、每日趋势、来源站点与最近访问时间；自动过滤爬虫、预览请求、浏览器预取和管理员自身点击。
- **掌控由你**：支持设置有效期、访问上限、临时或永久跳转，支持随时停用。修改目标网址即刻生效。
- **标签管理**：网址、文本和文件均可分配彩色标签，支持按标签与未标记项目筛选；标签只对管理员可见。
- **兼顾文本与文件分享**：支持在 `/p/…` 下分享笔记、代码或文件，同样支持设置有效期、访问上限与统计（详见[日常使用](./usage#shares)）。
- **极简部署**：单二进制内嵌管理界面，搭配单一 SQLite 文件。Docker 镜像约 25 MB，无需 Redis、PostgreSQL 等外部服务。
- **中文友好**：原生支持 `s.example.com/简历` 等中文短码；管理端与公开页面均内置中英双语。

## 适用场景

Sani 适合需要**完全自主掌控**短链接的个人用户：用于博客、周刊、社媒分享，提供稳定持久的短链接，免去第三方服务商关停、改则或插广告的担忧；也适合在私有服务器或小规格 VPS 上随手部署。

若你需要以下功能，Sani 可能并不适合：

- **多用户协作**：仅设单管理员密码，无多账号、团队或权限体系。
- **深度访客分析**：不收集地理位置、设备、浏览器等隐私数据（如需分析请在目标站点部署工具）。
- **复杂流量分流**：不支持按地域、设备或权重分流。
- **多实例高可用**：缓存与待刷盘点击位于单进程内存中，不支持多个进程同时服务同一数据库。应部署单个实例，并按实际数据与流量验证容量。

项目仍处于 0.x 阶段。准备对外服务时，请先阅读[版本与兼容](../project/versioning)，配置 HTTPS、持久化存储与备份，并按[运维指南](./operations)演练恢复。

## 设计取舍

**单人掌控。** 仅设单一登录密码，脚本与自动化使用 API 令牌。省去多用户系统，大幅减少维护负担与攻击面。

**统计从简。** 保存每日点击与来源域名聚合，不记录逐条访问流水或在统计表中保存访客 IP、User-Agent。数据仍会随链接数量、活跃天数及来源数量增长；来源字段也需按部署的隐私要求管理（详见[统计口径](./statistics)）。

**跳转优先。** 缓存命中不等待数据库写入；冷加载仍需查询数据库并与计数刷盘协调，资源竞争也可能影响延迟。元数据抓取在后台执行。

**无需外部数据库。** 管理界面内嵌于二进制，SQLite 保存记录与文本，`files/` 保存上传内容。在线数据库快照用 `sani backup`；完整备份需停止所有写入后配套复制数据目录，不能直接复制运行中的 `sani.db` 代替备份。
