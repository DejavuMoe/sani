# 介绍

<p class="lead">Sani 是一个给个人用的短链接服务。它部署在你自己的服务器上，只有你一个管理员：把长链接变短，告诉你每条链接被点了多少次，其余时候不来打扰你。</p>

## 它能做什么

- **粘贴即得**：在管理界面的任意位置粘贴链接，按回车，短链接就生成并复制到了剪贴板。网页标题和网站图标在后台自动获取，方便以后辨认。
- **跳转足够快**：跳转目标常驻内存，统计写入不在跳转的路径上。在一台笔记本上，每秒可以处理约 13 万次跳转，并且每一次点击都被准确计数（见[性能](../internals/performance)）。
- **统计够用**：总点击、每日趋势、来源网站和最近一次访问。爬虫、链接预览、浏览器预取和你自己的点击都不计入。
- **每条链接都可控**：设置有效期、访问次数上限，选择临时或永久跳转，随时停用。修改目标链接后，下一次访问就会生效。
- **部署简单**：一个内嵌了管理界面的二进制文件，加一个 SQLite 数据库文件。Docker 镜像约 24 MB，不需要 Redis、PostgreSQL 或任何其他服务。
- **中文友好**：`s.example.com/简历` 这样的中文短码可以直接使用；管理界面和访问者看到的页面都有中文和英文。

## 适合谁

Sani 适合想要一个**完全由自己掌控**的短链接服务的人：写博客、发周刊、在社交媒体上分享，需要一批能长期使用的短链接，不担心服务商关停、改规则或者插广告；也适合在家里的服务器或一台小 VPS 上顺手部署一个。

如果你需要下面这些，Sani 可能不适合你：

- **多人使用**：Sani 只有一个管理员密码，没有账号、团队和权限。
- **详细的访客分析**：Sani 不记录地理位置、设备、浏览器这些信息。需要的话，可以在目标网页上使用你自己的分析工具。
- **按规则分流**：按设备、地区或比例把访问者送到不同的地址。

## 设计上的取舍

**一个人用。** 登录只有一个密码，脚本和快捷指令使用 API 令牌。少了用户系统，也就少了一大块需要维护和保护的东西。

**统计从简。** 数据库里只存聚合后的数字：每条链接每天被点了多少次、来自哪些网站。没有逐条的访问记录，所以数据库不会随访问量膨胀，也没有需要保护的访客个人信息。详见[统计口径](./statistics)。

**跳转优先。** 所有设计都服务于一件事：跳转要快，并且不受其他操作影响。写数据库、汇总统计、抓取标题都在跳转之外进行。

**不依赖外部服务。** 一个进程就是全部。备份就是复制一个数据库文件，迁移就是把它放到另一台机器上。
