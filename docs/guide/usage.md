# 日常使用

<p class="lead">管理界面用“链接、文本、文件”三个入口创建内容，并统一管理分享地址、标签和访问记录。以下是常用操作与边界说明。</p>

## 缩短链接

支持三种快捷录入方式：

- **全局粘贴**：在页面任意位置直接按 <kbd>Ctrl</kbd> <kbd>V</kbd>（Mac 为 <kbd>⌘</kbd> <kbd>V</kbd>），无需事先聚焦输入框。粘贴混合文本时，Sani 会自动识别并提取其中的有效网址。
- **拖拽输入**：将链接直接从浏览器其他标签页或第三方应用拖拽至界面。
- **手动输入**：省略协议前缀的网址（如 `example.com/a`）会自动补全 `https://`。

按 <kbd>回车</kbd> 提交后，短链接即刻生成并复制到剪贴板，列表首行同步展示。

网页标题与网站图标在后台异步抓取，通常数秒内完成解析；若抓取失败，列表默认显示目标域名。若需自定义标题，展开“更多选项”填写即可（手动设定的标题后续不会被自动抓取覆盖）。

同一目标网址支持重复缩短生成多条独立短码。书签小工具与移动端分享例外：若当前网页曾生成过短链接，将优先复用旧链接。

## 标签分组 {#tags}

创建短链接、文本或文件分享时，在“标签”一栏选择已有标签，或输入名称直接新建。每条内容最多 5 个标签，名称最多 24 个 Unicode 码点；首尾空白会去除，规范化后的名称不区分大小写。新标签可选择颜色，默认蓝色；每个实例最多 1,000 个标签。

展开链接详情后点击“编辑”可调整标签；保存后生效，取消保留原分组。新建标签会立即保存到目录，即使之后取消链接编辑，也可以在下次使用它。

列表上方可按单个标签或“未标记”筛选，与搜索、类型筛选同时生效。标签旁的数字统计全部未删除链接，不随筛选变化；停用、过期链接也在数量内。创建成功会清除筛选并显示新记录。桌面端在独立列显示标签，手机端在目标链接下方显示；创建时间只在详情中显示，排序菜单仍支持最近创建与最近访问。

标签仅供管理员管理，访客看不到。删除链接后撤销会恢复标签；标签和颜色也随 [链接导出](./import-export) 保存。

通过列表上方或选择器中的**管理标签**，可以搜索目录、查看未使用标签、全局修改名称和颜色，或删除标签。编辑内容时移除标签只影响该条内容；删除标签会移除全部关联（包括软删除内容的关联），保留内容与其他标签，但不能撤销。确认数量包含链接、文本、文件以及停用、过期内容。删除当前筛选标签后只清除该标签条件，保留搜索词和类型；标签较多时使用**更多标签**搜索。

编辑未保存内容时离开，会提供继续编辑、放弃修改、保存并离开；保存失败保留草稿。创建提交期间锁定对应表单，文件上传仍可取消。同一查询刷新保留已加载页面和选择，切换筛选则清空选择；查询失败的旧结果暂不可操作，分页失败仍可操作已加载内容并重试。

## 自定义短码 {#slugs}

若未指定短码，系统将自动生成。网址短码默认长度为 5 位，默认使用无歧义字符集 `23456789abcdefghjkmnpqrstuvwxyz`（31 个字符，彻底剔除 0/o、1/l/i 等易混淆字符），便于口头复述。随着数据量增加，若随机碰撞率上升，系统会自动扩增一位。可在设置页调整网址长度（3–32）和是否排除易混淆字符；显式 [`SANI_SLUG_LENGTH`](../reference/configuration#sani-slug-length) 优先于后台设置并锁定网址长度。分享长度独立设置，见下方说明。

自定义短码时，输入框右侧会实时检测可用性。规则如下：

- 支持全语言字母与数字（如 `简历`、`café`、`2026`）；
- 首字符之后允许包含 `-`、`_` 和 `.`，但不能以 `.` 结尾；
- 最大长度 64 个字符；
- 大小写不敏感，`/GitHub` 与 `/github` 指向同一条记录；
- 系统保留短码（禁止占用）：`admin`、`api`、`p`、`rest`、`healthz`、`robots.txt`、`favicon.ico`、`favicon.svg`、`apple-touch-icon.png`。

## 链接配置项

展开“更多选项”可在创建时配置，创建后亦可随时编辑：

| 选项 | 说明 |
|---|---|
| 有效期 | 永久有效，或设定 1 小时、1 天、7 天、30 天及精确截止时间。过期后访客将看到“链接已失效”页面。 |
| 访问上限 | 累计有效访问达到阈值后自动失效。仅有效计入统计的请求占用次数，详见[统计口径](./statistics#visit-limits)。 |
| 跳转方式 | **临时重定向**（302，默认）：可随时变更目标，每次访问均经过 Sani 统计。<br>**永久重定向**（301）：未设有效期和访问上限时允许浏览器缓存 1 天，期间同客户端不再回源 Sani，无法精准计数且目标变更存在延迟。带有效期或访问上限时，所有跳转方式均禁止缓存。API 额外支持 307 与 308。 |
| 停用状态 | 停用后访客访问展示“链接已失效”页面，重新启用即刻恢复。 |

## 修改与删除

- **编辑配置**：选中记录按 <kbd>E</kbd>，可变更目标网址、短码、标题及高级属性。保存后立即生效。
- **变更短码**：旧短码在保存后立刻释放失效。
- **变更目标**：若原标题为自动抓取，变更后将重新触发抓取流程。
- **删除**：按 <kbd>Del</kbd>（Mac 为 <kbd>⌘</kbd> <kbd>⌫</kbd>）。删除无阻断弹窗，底部提示条提供即时撤销选项。删除超过 1 小时后，后台清理记录与统计，文件再异步回收；复用短码会提前移除旧记录。详见[分享清理](./operations#share-cleanup)。
- **短码复用机制**：删除短码后，该标识立即可分配给新链接。一旦被新链接占用，原删除记录将无法再撤销恢复。

## 批量操作 {#bulk}

点击列表顶栏“多选”或选定条目按 <kbd>X</kbd> 进入批量模式。单选每行直接勾选，配合 <kbd>Shift</kbd> 可范围连选；批量操作栏左侧复选框支持全选当前加载的内容。

支持对最多 500 条内容执行一键启用、停用或删除。批量删除同样支持撤销。按 <kbd>Esc</kbd> 或点击“完成”退出多选。

配合搜索关键词过滤后再行全选，可批量处置特定活动或标签链接。切换搜索词或排序规则时会自动清空勾选，防止误操作视区外的隐藏记录。

## 文本与文件分享 {#shares}

除短链接外，Sani 支持分发文本片段或二进制文件。点击顶部“文本”或“文件”标签切换，或在页面中直接录入：

- **粘贴文字**：粘贴多行文字或非链接文本时，自动填入“文本”标签。
- **拖放文件**：拖入或粘贴文件自动转入“文件”标签等待上传。默认单文件上限 99 MB，可通过 [`SANI_MAX_FILE_MB`](../reference/configuration#sani-max-file-mb) 自定义。

文本支持两种格式：**纯文本**（自适应普通排版与换行）与**代码**（等宽字体、行号、保留原始缩进）。单条文本上限 1 MB，内容不进行解析渲染，Markdown 与 HTML 均安全原样呈现。

按 <kbd>Ctrl</kbd> <kbd>回车</kbd>（Mac 为 <kbd>⌘</kbd> <kbd>回车</kbd>）或点击“分享”开始提交。大文件支持实时进度展示与取消上传。生成的分享链接形如 `s.example.com/p/k3m9x2qv7h`。有效期、访问上限和停用规则与链接完全一致。访问上限设为 1 表示一次有效访问，不会在访问后自动销毁内容；过期内容继续保留，手动删除后才进入[后台清理](./operations#share-cleanup)。

新安装时，文本／代码与文件分享短码分别默认生成 10 位随机字符，可在“设置 → 创建默认值”中独立设为 3–32 位，长度不含 `/p/`。对应 [`SANI_TEXT_SLUG_LENGTH`、`SANI_FILE_SLUG_LENGTH`](../reference/configuration#sani-text-slug-length)，显式环境值分别锁定自己的字段；后台保存的值在重启后保留。分享始终排除 0/o、1/l/i 等易混淆字符，不受网址的字符开关影响。低于 10 位可正常保存和生成，没有隐藏的 10 位下限；后台会提示短码越短越容易被猜中。分享没有公开检索列表，但知道地址的人即可访问。用户亦可自定义指定短码。

旧实例首次升级时，会按 `max(10, 旧版有效网址短码长度)` 保存尚未独立设置的分享长度，例如原网址长度为 12 时仍生成 12 位分享短码。之后修改网址长度不再影响文本或文件分享；已有及手动指定的短码不变，碰撞重试与扩长规则也不变。

访客访问页面时可直观查看文本并一键复制；配置[独立文件域名](./deploy#files-domain)后，额外提供“原始文本”直链与“下载”按钮。文件分享页完整展示文件名、MIME 类型、体积、SHA-256 哈希及下载按钮。所有文件流均严格由独立文件域名托管，隔离主域 Cookie 与 XSS 风险，防止恶意文件仿冒服务主站。

在管理列表中，分享项短码带有 `/p/` 前缀并使用对应图标标识。展开详情可直接查阅文本内容、文件名与哈希校验码，支持“复制文本”或“复制下载链接”。管理后台刻意不提供直接下载按钮，避免管理员自测误占访问上限。修改文本按 <kbd>E</kbd> 即可；文件一旦上传无法替换，需变更请新建分享。

## 检索与排序

全局搜索支持匹配短码、标题、目标网址、文件名及首行文本内容，在任意界面按 <kbd>/</kbd> 即可快速唤起。直接粘贴完整短链接亦能精准定位。类型下拉框支持在“全部类型”、“链接”、“文本”、“文件”之间快速切换。

列表支持按“最近创建”、“访问最多”与“最近访问”三种维度排序。

## 详细指标面板

点击列表条目或选中后按 <kbd>回车</kbd> 展开详细面板：

- 总访问、今日访问、最后访问时间、创建时间，以及有效期与访问上限消耗进度；
- 近 7 天、30 天或 90 天的每日访问柱状图趋势；
- Top 来源域名排行；
- 二维码预览（支持导出 PNG 或 SVG）；
- 编辑、停用、删除及“重新获取标题”等快捷操作。

## 浏览器书签脚本

进入 设置 → 快捷方式，将“缩短此页”按钮拖至浏览器书签栏。在浏览任意网页时点击该书签，会弹出已填入当前网址与标题的迷你窗口。核对后点击“缩短”，即可生成短链接、自动复制到剪贴板并显示二维码。若该页面此前已生成过短链接，则复用旧链接；仅打开窗口不会创建链接。

## 移动端适配与 PWA

在手机浏览器访问管理后台并选择“添加到主屏幕”，即可作为独立应用（PWA）运行。Android 系统下会自动注册系统分享目标：在任一应用中调用“分享到 Sani”，会先填入分享的网址与标题，确认并点击“缩短”后才生成短链接和二维码。

## 脚本自动化

在 设置 → API 令牌 中生成持久令牌，即可在自动化脚本、快捷指令（iOS Shortcuts）或插件中调用 [HTTP API](../reference/api)：

```sh
curl https://s.example.com/api/links \
  -H "Authorization: Bearer sani_…" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/some/long/path"}'
```

API 令牌拥有全部管理员权限，修改主密码后不受影响。令牌仅在生成时显示一次明文，废弃时请及时撤销。

## 访客端行为表现

- **无感直跳**：访客请求短链接时直接输出 HTTP 重定向响应，无任何过渡页面或中间等待。
- **透传查询参数**：访客携带的 URL Query 会自动合并拼接至目标网址（如 `s.example.com/gh?utm_source=x`）。若需禁用可配置 [`SANI_FORWARD_QUERY`](../reference/configuration#sani-forward-query)。
- **容错重定向**：短码尾部多带斜杠 `/` 或大小写变体均可正常重定向。
- **文本与文件展示**：必须通过 `/p/{短码}` 访问，页面根据客户端语言适配展示；直接请求根路径 `/{短码}` 会返回 404。
- **状态码与异常页**：未命中短码返回 404；已过期、停用或配额耗尽返回 410。错误页轻量快速，根据浏览器语言响应中英双语，并默认附带 `noindex` 标识防止搜索引擎索引。

后台“创建默认值”分别设置网址、文本／代码和文件的自动短码长度（各为 3–32），以及网址是否排除易混淆字符和完整文件上限。标签提供 12 个柔和预设、应用内 RGB 滑块及 HEX/RGB/HSL 输入；编辑标签会同步更新所有引用。超过 25 MB 的文件自动分片，失败后保持当前页面可从已确认分片处重试，也可取消上传；刷新页面不支持续传。

## 网页信息与代理

在设置 → 网页信息中开启自动获取，然后选择直接连接、HTTP(S) 或 SOCKS5。代理的主机、端口和可选认证直接在后台填写。HTTP(S) 的 HTTPS 开关控制到代理这一跳的加密；SOCKS5 不提供这一层加密。没有内置公共商业中继。测试连接只验证当前表单，点击保存后新请求才使用它。失败不会自动直连；关闭抓取仍可手动填写标题。

已保存密码不会回显，可替换或取消替换；要清除认证凭据，关闭身份认证再保存。更换代理地址、协议、端口或账号需重新输入密码。环境变量固定的配置显示为只读；[配置说明](../reference/configuration#sani-meta-proxy)列出优先级和密码存储方式。

有效期的自定义时间使用应用内日历，日期和时间可以键入；点击“应用时间”确认，再保存链接。使用当前设备时区，拒绝无效或已过去的时间。悬浮提示也支持键盘焦点与 Escape 关闭。
