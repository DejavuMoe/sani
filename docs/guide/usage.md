# 日常使用

<p class="lead">管理界面围绕一件事设计：尽快把链接缩短并交到你手上。下面是常用的操作，以及一些不太容易发现的细节。</p>

## 缩短链接

有三种方式把链接交给 Sani：

- **粘贴**：在页面任意位置按 <kbd>Ctrl</kbd> <kbd>V</kbd>（Mac 上是 <kbd>⌘</kbd> <kbd>V</kbd>），不用先点输入框。粘贴一段带链接的文字也可以，Sani 会从中找出链接。
- **拖放**：把链接从别的标签页或应用拖到页面上。
- **输入**：`example.com/a` 这样不带协议的地址会自动补上 `https://`。

然后按 <kbd>回车</kbd>。短链接生成后会自动复制到剪贴板，列表最上面多出一行。

网页标题和网站图标在后台获取，通常几秒内出现；获取不到时，列表显示目标网站的域名。想自己写标题，展开“更多选项”填写，自己写的标题以后不会被覆盖。

同一个网址可以缩短很多次，每次都是一条新的短链接。书签小工具和手机分享是例外：如果这个网页以前缩短过，会直接给你原来那条。

## 短码 {#slugs}

不填短码时，Sani 会自动生成。生成的短码默认 5 位，只用 `23456789abcdefghjkmnpqrstuvwxyz` 这 31 个字符，去掉了 0 和 o、1 和 l、i 这些容易认错的字符，念给别人听也不会出错。已有的链接越来越多、随机生成开始频繁撞车时，新短码会自动加长一位。长度可以用 [`SANI_SLUG_LENGTH`](../reference/configuration#sani-slug-length) 调整。

自己指定短码时，输入框旁边会实时显示是否可用。规则是：

- 可以使用任何语言的字母和数字，比如 `简历`、`café`、`2026`；
- 第一个字符之后，还可以使用 `-`、`_` 和 `.`，但不能以 `.` 结尾；
- 最多 64 个字符；
- 不区分大小写，`/GitHub` 和 `/github` 是同一条链接；
- 以下短码由 Sani 自己使用，不能占用：`admin`、`api`、`rest`、`healthz`、`robots.txt`、`favicon.ico`、`favicon.svg`、`apple-touch-icon.png`。

## 链接选项

展开“更多选项”，可以在创建时设置这些选项，创建之后也随时可以修改：

| 选项 | 说明 |
|---|---|
| 有效期 | 永久有效，或者 1 小时、1 天、7 天、30 天，也可以指定具体时间。过期后，访问者会看到“链接已失效”页面。 |
| 访问上限 | 被访问多少次之后失效。只有计入统计的访问才占用次数，见[统计口径](./statistics#visit-limits)。 |
| 跳转方式 | **临时**（302，默认）：可以随时修改目标，每一次访问都会经过 Sani。**永久**（301）：浏览器会缓存一天，这段时间里同一个浏览器的访问不再经过 Sani，所以不计数，修改目标也要等缓存过期才生效。API 还支持 307 和 308。 |
| 停用 | 停用后访问者会看到“链接已失效”页面，重新启用即可恢复。 |

## 修改与删除

- **修改**：选中链接后按 <kbd>E</kbd>，可以修改目标、短码、标题和上面的选项。保存后，下一次访问就按新的设置跳转。
- **改短码**：保存后旧短码立即失效。
- **改目标**：如果标题是自动获取的，会重新获取新目标的标题。
- **删除**：按 <kbd>Del</kbd>（Mac 上是 <kbd>⌘</kbd> <kbd>⌫</kbd>）。删除不弹确认框，提示条上可以撤销。删除一小时后，链接和它的统计会被彻底清除。
- **短码的复用**：删除后，这个短码马上可以分配给新的链接。一旦被新链接占用，旧链接就不能再恢复了。

## 批量操作 {#bulk}

点列表上方的“选择”，或者选中一行后按 <kbd>X</kbd>，进入选择模式。这时点一行就是勾选它，按住 <kbd>Shift</kbd> 再点另一行，可以勾选两行之间的所有链接；操作栏最左边的方框可以一次勾选全部已加载的链接。

勾选之后，操作栏可以一次启用、停用或删除它们，最多 500 条。删除同样可以在提示条上撤销。按 <kbd>Esc</kbd> 或者点“完成”，退出选择模式。

先搜索再全选，就能一次处理一批相关的链接，比如停用某次活动的全部短链接。换一个搜索词或排序时，已勾选的链接会被清空，免得处理到看不见的链接。

## 查找与排序

搜索框按短码、标题和目标网址查找，按 <kbd>/</kbd> 就能开始输入。把完整的短链接粘贴进去，也能找到对应的那一条。

列表可以按“最近创建”“点击最多”和“最近访问”排序。

## 链接详情

点击一行，或者选中后按 <kbd>回车</kbd>，可以展开详情：

- 总点击、今天的点击、最近一次访问、创建时间，以及有效期和访问上限的使用情况；
- 最近 7 天、30 天或 90 天的每日点击；
- 主要的来源网站；
- 二维码，可以下载 PNG 或 SVG；
- 编辑、停用、删除，以及“重新获取标题”。

## 键盘快捷键 {#keyboard}

在管理界面里按 <kbd>?</kbd> 可以随时查看。

| 按键 | 作用 |
|---|---|
| <kbd>N</kbd> | 新建短链接 |
| <kbd>Ctrl</kbd> <kbd>V</kbd> / <kbd>⌘</kbd> <kbd>V</kbd> | 在任意位置粘贴链接 |
| <kbd>/</kbd> | 搜索 |
| <kbd>J</kbd> / <kbd>K</kbd>，或 <kbd>↓</kbd> / <kbd>↑</kbd> | 上下选择 |
| <kbd>回车</kbd> | 展开或收起详情 |
| <kbd>C</kbd> | 复制短链接 |
| <kbd>E</kbd> | 编辑 |
| <kbd>Ctrl</kbd> <kbd>回车</kbd> / <kbd>⌘</kbd> <kbd>回车</kbd> | 保存修改 |
| <kbd>Del</kbd> / <kbd>⌘</kbd> <kbd>⌫</kbd> | 删除（可撤销）；有勾选的链接时，删除全部勾选的链接 |
| <kbd>X</kbd> | 勾选或取消勾选，用于[批量操作](#bulk) |
| <kbd>Esc</kbd> | 收起或清除 |
| <kbd>?</kbd> | 显示快捷键 |

## 书签小工具

打开设置 → 快捷方式，把“缩短此页”按钮拖到浏览器的书签栏。之后在任何网页上点击这个书签，都会弹出一个小窗口：当前页面被缩短，短链接复制到剪贴板，旁边还有二维码。如果这个页面以前缩短过，就直接给你原来那条。

## 在手机上

用手机浏览器打开管理界面，选择“添加到主屏幕”，Sani 就像一个应用一样出现在桌面上。在 Android 上，它还会出现在其他应用的“分享”菜单里：在任何应用里把链接分享给 Sani，它会立即被缩短，窗口里有复制按钮和二维码。

## 在脚本里使用

在设置 → API 令牌里创建一个令牌，就可以在脚本、快捷指令或浏览器扩展里调用 [HTTP API](../reference/api)：

```sh
curl https://s.example.com/api/links \
  -H "Authorization: Bearer sani_…" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/some/long/path"}'
```

令牌拥有完整权限，修改密码后依然有效。它只在创建时显示一次，不再使用时请撤销。

## 访问者看到什么

- **跳转**：访问者打开短链接，会被直接送到目标网址，中间没有任何页面。
- **查询参数**：访问者带来的查询参数会拼接到目标网址上，比如 `s.example.com/gh?utm_source=x`。不需要的话，用 [`SANI_FORWARD_QUERY`](../reference/configuration#sani-forward-query) 关闭。
- **写法宽容**：短码末尾多一个 `/`，或者大小写不同，都能正常跳转。
- **出错页面**：短码不存在时显示 404 页面，链接过期、停用或者访问次数用完时显示 410 页面。页面按访问者浏览器的语言显示中文或英文，并告诉搜索引擎不要收录。
