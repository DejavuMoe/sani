## 组件与尺寸

| 控件 | R10 桌面 | R10 窄屏或粗指针 |
|---|---:|---:|
| 常规动作 / 工具栏 / 分段外框 | 28px | 36px |
| 单行字段 / 与字段成组的动作 | 32px | 40px |
| 数字框 | 56×32px | 54×36px |
| 菜单选项行 | 至少 36px | 至少 44px |
| 大号按钮 | 36px | 40px |

以上为默认字号下的尺寸。文字放大时按钮和输入框允许长高，分段选项允许换行，不使用裁切来维持固定外框。

数字与单位统一使用 `UnitInput`，三种短码和文件大小复用同一结构。整数校验、单位说明、错误描述、只读来源和保存反馈保留。点击单位可聚焦字段，不增加加减按钮。

Button、Segmented、输入框、搜索框以所属布局的尺寸变量统一外框，分段内部扣除 4px 内边距。连接选项按内容宽度排列；标签搜索与范围切换、域名与保存、令牌与创建、代理字段与密码动作保持成组对齐。数字使用等宽数字，地址与代码保留等宽字体，中文说明使用更舒展的行高。手机可编辑文本保持 16px。

按钮的透明命中区域扩展到至少 44×44px，段选项与相邻图标留出对应间隔；数值输入和普通字段的实际输入区域仍分别是 36px / 40px 高。不会把透明命中区域误报为字段本身已经达到 44px。需要真机确认手指操作与虚拟键盘体验。

## 交互与内容

- 保存时加载图标居中覆盖原内容，保留原标签占位和可访问名称，按钮宽度不跳变。
- Segmented 增加 Home / End 首尾键；方向键、Tab、禁用状态继续有效。
- Menu 对短视口限高、滚动与边界定位；关闭返回入口，卸载移除监听。与当前生产修复保持一致。
- 动效限制在 80–180ms 的按下、颜色、浮层和通知反馈；减少动态效果偏好取消位移并收敛时长。
- API 令牌示例同步为 `POST /api/v1/links`、`target_url`；固定域名及升级备份说明采用当前生产文案。文件自动分片阈值核对为十进制 25 MB（`UPLOAD_CHUNK_SIZE = 25_000_000`），沿用当前源码单位。
- 原型保存、连接测试、上传和凭据使用隔离示例及模拟状态，不访问生产 API，也不验证真实代理连接。
