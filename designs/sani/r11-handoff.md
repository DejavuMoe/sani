## 访问密码

| 位置 | 设计 |
|---|---|
| 创建（链接、文本、文件） | 选项行中，“有效期 / 访问次数 / 访问密码”三项并排放在提交按钮前，均显示为图标加当前值。“访问次数”从“更多”移出；“更多”只保留标题，短链额外保留跳转方式。 |
| 密码弹层 | 打开时已生成 6 位密码并全选（字符集排除 0/O、1/I/L），回车即可确认；可重新生成或自行输入（4–64 个字符）。已设置时显示“移除密码”。 |
| 创建完成 | 剪贴板内容为链接加一行“密码：XXXXXX”，提示“已复制链接和密码”。 |
| 列表 | 标题后显示锁形图标（可访问名称“已设访问密码”）。复制按钮会同时复制链接和密码。 |
| 详情 | 侧栏“访问密码”一行，默认遮蔽，可显示、复制。主按钮变为“复制链接和密码”。 |
| 编辑 | “访问密码”字段配“生成”按钮；清空即移除。 |
| 访问者 | 页面包含：锁形图标、“输入访问密码”、短链地址、输入框、“继续”按钮。错误状态分为：未输入、密码不正确、尝试次数过多。页面是无脚本也能用的普通表单。比对不区分大小写。 |

后端方案（实现阶段再细化，本轮未改动生产代码）：

- **存储**：`links.password`，通过 `PRAGMA user_version` 迁移，同时写进导入导出。
- **API**：创建和修改接口新增 `password` 字段，`PATCH` 传空字符串表示移除；新增错误码 `password_invalid`。
- **解锁**：访问者通过 `POST /{slug}` 或 `POST /p/{slug}` 提交密码，按 IP 加短码限流，map 有容量上限。
- **解锁凭据**：文本和文件设置 HttpOnly cookie，路径只限当前分享，签名包含链接 ID 和密码，所以改密码后旧 cookie 立即失效。文件域名不同源，用短时效的签名参数 `?t=`。
- **计数**：输错密码不计次数，解锁后才计。
- **跳转热路径**：缓存条目只多一个“是否受保护”标记，未设密码的链接，跳转路径完全不变。
- **CSP**：分享页的 `form-action` 需改为 `'self'`。

## 视觉规范

| 规则 | 实现 |
|---|---|
| 颜色 | 全部换成 Radix Colors：Slate 作中性色，Indigo 作强调色，Red、Green、Amber 作状态色；沿用原有 token 名称，见 `src/r11/theme.css`。 |
| Radix 色阶用法 | 第 1–2 阶作背景，3–5 阶作组件状态，6–8 阶作线条，第 9 阶作实心按钮（第 10 阶为悬停），11–12 阶作文字。深色模式下强调色文字用 Indigo 11，因为 Indigo 9 作文字对比度只有 3.4:1。 |
| 次要文字 | Slate 11 是唯一能达到 4.5:1 的次要文字色阶，所以次要层级改靠字重和间距区分，不用颜色区分。 |
| 0.5px 线条 | 浏览器会把小于 1 设备像素的边框向上取整，实测 Chromium 会把 0.5px 边框按 1px 计算。因此线条改用 inset 0.5px 阴影绘制：每条边的颜色是一个不继承的自定义属性（`@property --hbt/--hbr/--hbb/--hbl`），状态颜色仍由原来的选择器设置。2x 屏上是真正的 0.5px，1x 屏上会显示为较淡的 1px。 |
| 字号 | 后台只用 12/13/16/20 四档，访问者页面只用 12/13/16 三档；手机端输入框按 16px 处理（防止 iOS 点输入框时页面自动放大），它和标题同属 16 这一档。 |
| 圆角 | 同心：外层 12px、内边距 4–6px 时，内层用 8/6px（菜单、弹层、创建框选项行）。 |
| 阴影 | 只保留浮层阴影（菜单、弹层、对话框、通知）。去掉了按钮、分段控件、创建框的阴影，以及选中行左侧的彩色竖条（改为底色）。 |
| 动效 | 悬停颜色瞬时切换；浮层和通知用 250ms ease-out；去掉了输入框脉冲、骨架呼吸、选中行闪烁、抖动等动画。 |
| 中点分隔符 | 所有“·”分隔改为 12px 间距。用户数据（例如示例标题）保留原文。 |
| 说明文字 | 移除了创建框和详情页里的规则说明、“正在提交”提示、统计口径折叠说明、“停用后访问会显示…”提示；永久跳转的缓存说明保留一句。 |
| 标签预设色 | 换成 Radix 第 9 阶。已保存的自定义颜色按原值显示；旧版五个颜色名映射到 Radix 对应色。 |

### 与原型的差异

- **跳转热路径**：未设密码的跳转只多一次字符串判空。基准对比 5 轮平均：基线 540 ns/op，R11 528 ns/op，两者都是 440 B/op、5 次分配，差异在噪声范围内。
- **英文文案**：英文 `Password` 改为 `Access password`，避免与重新登录时的账号密码字段同名。中文仍为「访问密码」。
- **成功色**：Radix Green 11 放在 Slate 2 背景上对比度只有 4.48:1，改用同属 Radix 的 Grass 11（浅色 `#2a7e3b`，深色 `#71d083`），达到 4.8:1。
- **短链密码页的 CSP**：`form-action` 额外放行目标网址的来源。浏览器会把表单提交后的 303 重定向也算作表单目标，只写 `'self'` 时跳转会被拦截。这个问题由端到端测试发现，Go 测试已补上对应断言。
- **字体**：访问者页面受 CSP 限制不加载网页字体，生产中使用系统字体，原型中使用 Inter 和 IBM Plex Mono。
- **布局修正**：英文宽屏下文本创建框的选项行会换行，此时提交按钮保持在行末。密码页报错状态只保留一层红色焦点环。
- **删除的提示与文案键**：删除了统计口径折叠说明、分片上传提示、「停用后…」提示及其对应的文案键。
